## Running the App

```bash
python main.py
```

No build step. Dependencies: `python-gobject`, `libadwaita`, `pamixer`, `python-cairo` (Arch: `sudo pacman -S --needed python-gobject libadwaita pamixer python-cairo`). `python-cairo` is required by `monitor.py` for the drag-and-drop canvas.

For Rust module development (optional): `rust`, `cargo`, `clippy`, `rust-analyzer` (Arch: `sudo pacman -S --needed rust` then `rustup component add clippy rust-analyzer`).

## Architecture

GTK4/Libadwaita settings app for Hyprland + Caelestia. Pure Python, no framework beyond PyGObject.

- **`main.py`** — `Adw.Application` entry point; calls `get_config_dir()` early to ensure config dir exists.
- **`src/window.py`** — `MainWindow(Adw.ApplicationWindow)`: sidebar (`Gtk.StackSidebar`) + page stack (`Gtk.Stack`). All pages register here. `win.add_toast(Adw.Toast.new("..."))` is the app-wide feedback pattern.
- **`src/config.py`** — All path constants (`HYPR_*`, `CONFIG_DIR`, `APP_DATA_DIR`) and helpers for reading/writing `monitors.json`, `window_rules.json`, and parsing `monitors.conf` / `rules.conf`.
- **`src/lang.py`** — i18n via `t("English string")`. Auto-detects German from `LANG`. All UI strings must go through `t()`. Translations live in the `TRANSLATIONS` dict — English is always the key.
- **`src/pages/`** — One file per page. Each is a GTK widget that receives `win` (MainWindow) as its first constructor argument.

- **`rust/`** — Cargo workspace, crate `caelestia-core`. Pure, tested parser/logic modules (no GTK/UI code, no file I/O): `keybinds.rs` (variables.conf), `config.rs` (monitors.conf), `rules.rs` (rules.conf), `window_rule_conflicts.rs` (conflict detection, ported from window_rules.py), `fans.rs` (PWM percentage conversion). PyO3 bindings to Python pending (see README roadmap). Each module has its own `#[cfg(test)] mod tests`; run with `cd rust && cargo test --workspace`.

**Path constants are not fully centralized.** `config.py` holds the main Hypr paths, but `keybinds.py` defines `KEYBINDS_CONF` and `VARIABLES_CONF` locally, and `wallpaper.py` defines `_SHELL_JSON`, `_DEFAULT_IMAGE_DIR`, `VIDEO_DIR`, and `THUMB_CACHE` locally. When editing paths in these pages, look in the file itself, not `config.py`.

**Threading pattern.** Background work (thumbnail generation, Wi-Fi scan, system update) runs in `threading.Thread`. All GTK UI updates from those threads must go through `GLib.idle_add(callback)`.

**Live reload via `hyprctl`.** Monitor, workspace, keybind, and window-rule changes are applied immediately with `hyprctl reload` or `hyprctl keyword ...`. No Hyprland restart needed.

**Two separate update flows:**
- **App self-update** (About page): calls `app_update.sh` in a `kitty` terminal — does a `git pull` of the app itself.
- **System update** (Updates page): runs an inline bash script via `subprocess.Popen` with a sudo password piped via `SUDO_ASKPASS`; runs `yay -Syu`.

**Workspace and rules managed blocks.** `workspaces.py` writes its block delimited by `# Workspaces – Auto-generated by Caelestia Settings`. `window_rules.py` uses `# Auto-generated by Caelestia Settings – Fenster-Regeln`. Lines outside these markers are never touched.

## Testing and Linting

`ruff.toml` (Python) + `.github/workflows/ci.yml` (CI) define checks:
- **Python**: `ruff check main.py src/` (targets Python 3.12)
- **Rust**: `cargo fmt --all -- --check && cargo clippy --workspace --all-targets -- -D warnings && cargo test --workspace` (in `rust/`)
- **Security**: `gitleaks` secret scanning

CI triggers on push/PR to `main` and `dev`. Run the same commands locally to reproduce CI results.

## Adding a New Page

1. Create `src/pages/mypage.py` with a class extending a GTK container widget.
2. Accept `win` as the first argument; use `win.add_toast(...)` for notifications.
3. Import and add to the stack in `src/window.py`.
4. Add any new UI strings to `TRANSLATIONS` in `src/lang.py`.

## i18n Rules

- Always use `from src.lang import t` and wrap every user-visible string in `t("...")`.
- The English string is both the key and the fallback — it must be meaningful on its own.
- Add German translations to `TRANSLATIONS` in `src/lang.py` for every new string.

## Config Files the App Modifies

| Constant | Path |
|----------|------|
| `HYPR_INPUT_CONF` | `~/.config/hypr/hyprland/input.conf` |
| `HYPR_MONITORS_CONF` | `~/.config/hypr/hyprland/monitors.conf` |
| `HYPR_RULES_CONF` | `~/.config/hypr/hyprland/rules.conf` |
| `HYPR_KEYBINDS_CONF` | `~/.config/hypr/hyprland/keybinds.conf` |
| — | `~/.config/hypr/hyprland/execs.conf` |
| — | `~/.config/caelestia/shell.json` |
| `WINDOW_RULES_CONFIG_FILE` | `~/.config/caelestia-settings/window_rules.json` |

The managed block in `rules.conf` is delimited by `# Auto-generated by Caelestia Settings – Fenster-Regeln`. Manual rules outside this block are never overwritten.

## Installation

```bash
./install.sh   # copies app to ~/.local/share/caelestia-settings/, creates ~/.local/bin/caelestia-settings
```

The installer also wires Hyprland config (rules, `Super+I` bind, `monitors.conf` source). App version is read from `manifest.json`.
